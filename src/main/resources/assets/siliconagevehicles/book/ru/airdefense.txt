# Как устроена ПВО
РЛС видят летающую технику, командный пункт (КП) ведёт треки и решает по правилам огня, зенитная установка и ракетный комплекс стреляют. По умолчанию сервер **только предупреждает**: огонь включает настройка airdefense.mode = fire.
@note По своим машинам, машинам из списка доступа, по коду 7700 и своим кодам ПВО не стреляет никогда.

# Ответчик
У всего, что летает: ВЫКЛ / ДЕЖ / A (код 0000-7777) / C (+ высота) / S (+ номер борта). Панель - меню "Техника", строка "Ответчик": цифры, режим, 7000 / 7600 / 7700, "Ключ дня". IDENT - клавиша \: отметка мигает 18 с на всех радарах. Новая машина - режим C, код 7000.
**Ключ дня**: секрет КП + номер игровых суток = код дня. "Карта кодов" (2 бумаги + синий краситель): ПКМ по КП - на карте код на сегодня; ответчик с "Ключом дня" сам берёт код с карты в инвентаре. Вчерашняя карта даёт вчерашний код - для ПВО это чужой.

# Зоны и правила огня
**Зоны** - запретная, ограниченная, аэродром, коридор; круг или прямоугольник (с поворотом), высоты от-до. Пилоты видят их на карте, HSI, ND лайнера и рамкой на HUD; прогноз "ВХОД В ЗОНУ ... ЧЕРЕЗ N С" (airdefense.zoneWarnSeconds = 30), за треть времени - красный и второй тон.
**Правила огня** КП: запрещён / по нарушителям зоны / по всем чужим / по отметкам КП. Перед огнём - сообщение пилоту, через 5 с захват, ожидание (не меньше airdefense.minWarningSeconds), предупредительные трассеры, затем огонь.

# Командный пункт
Карта с зонами, РЛС, ПУ и треками (свой / чужой / нарушитель / 7700), формуляр, список отметок, журнал, ТРЕВОГА (редстоун 15), "Авто", печать карт кодов, сообщение пилоту. Меню по ПКМ на треке: назначить ПУ, авто, только вести, "свой на 10 минут", сообщение.
- Вкладка **"Зоны"**: тянуть углы, стороны и центр мышью, кружок - поворот, "Сетка 8", копировать / вставить / отменить.
- **"Настройки"**: название, ключ дня и секрет, свои коды, белый список Mode S, доверенные аэродромы, доступ.
- **"Оборудование"**: энергия, вход, слоты модулей.
- **Карта покрытия** РЛС ("Покр.: 20 / 60 / 120 бл"): зелёный - видно, красный - мёртвые зоны за рельефом.

# Коды аэродрома, IFF и 7600
- Вышка выдаёт коды 4100-4177: вылетающему - с разрешением на взлёт, прилетающему - при входе в зону с режимом C. Лайнеру - по CPDLC ("ПРИНЯЛ" ставит код), остальным код ставится сам.
- Борт с кодом своего аэродрома у аэродрома (160 блоков) - СВОЙ: ни тревоги, ни огня (airdefense.airportFriends).
- **IFF**: РЛС владельца вышки опрашивают борта. Молчит или чужой код - тревога "НАРУШ.", вызов пилоту; ответ - включить ответчик или ответить по CPDLC. Нет ответа за 30 с - передача ПВО (airdefense.iffHandoff, по умолчанию выкл.).
- **7600** (нет связи): на КП трек "НЕТ СВЯЗИ" с таймером 120 с и решение "Свой" (на 10 минут) или "Проверить"; без решения - обычный порядок.

# Модули и правила сервера
4 слота модулей ядра у каждого блока: универсальный трансформатор, трансформатор, накопитель, ускоритель, экономайзер, форсаж (только РЛС), захват (только ПУ). Сломанное сооружение уносит модули в своём предмете.
Правила сервера (раздел airdefense): enabled, mode (warnings / fire), fireInProtectedRegions, fireOnFriends, requirePvp, fireOnUnmanned, maxLaunchersPerPlayer, maxRadarsPerPlayer, minDistanceFromSpawn, minWarningSeconds, launchLog (logs/airdefense.log), damageMultiplier, dayKey.
