# Silicon Age: Vehicles — план аддона (черновик 2026-10-06)

Название утверждено 2026-10-06: **Silicon Age: Vehicles** (в игре по-русски — «Кремниевый век: Техника»), modid `SiliconAgeVehicles`.

Отдельный мод-аддон, ядро Silicon Age не меняется. ★ — рекомендация. Все числа черновые, правятся при балансе.
Крафты — **только предметы Silicon Age + ванильные**. Макеты: `docs/mockups/`.

## 0. Принципы
1. **Своя ниша у каждой машины** — техника не повторяет броню и мост: груз, группа игроков, тяжёлая работа,
   дальние перелёты дёшево, ранняя мобильность.
2. **Инфраструктура — цена удобства**: машина дешевле брони за блок пути, но её надо заряжать, заправлять, ремонтировать
   и где-то хранить (гараж, станции, полоса).
3. **EU — основной ресурс, газы — для особых режимов** (полёт, охлаждение, защита, дальние прыжки). Без газа машина
   работает в базовом режиме, без EU — аварийный режим (ползёт / планирует / авторотация), не ломается.
4. **Модульная сборка**: машина = корпус + двигатель + энергоблок + бортовой компьютер + ходовая + модули. Компоненты
   ставятся в Гараже, улучшаются заменой (как модули машин мода).
5. **Безопасность сервера**: владелец и доступ как у полей мода, чужие приваты не трогаются, машины не грузят чанки,
   не исчезают; лимит машин на игрока — в конфиге (по умолчанию без ограничений).

## 2. Машины (что делает, для чего)
Расход EU: `база простоя + k × скорость² × (1 + груз/грузоподъёмность)`; стоя — почти ноль.

### Особые механики
- **Аварийные режимы**: багги/вездеход ползут 10% скорости; вертолёт — ★ авторотация (спираль вниз, мягкая посадка);
  самолёт — планирование 1:8 и посадка на брюхо с износом; ховербайк садится на землю.
- **Нагрев**: двигатель греется от нагрузки, гелий снимает. 100% — глохнет до 50%.
- **Сваливание у самолётов**: ниже минимальной скорости нос опускается; зависать нельзя.
- **Крейсерская высота**: самолёт выше Y 100 тратит на 20% меньше.
- **Подвес грузового вертолёта**: сундук (с содержимым), машина мода, блок без tile entity; чужие приваты — нельзя.
- **Автопилот**: координатор моста задаёт маршрут (до 8 точек); вездеход ездит, самолёт летит сам.
- **Износ** — включён всегда по умолчанию (конфиг `vehicles.wear = true`, можно выключить): урон корпусу от ударов и мобов, ремонт в Гараже слитками корпуса.

## 3a. Инженерный верстак (решение 2026-10-06, вариант 1)
- Одиночный блок, уровень MV, питание от сети Silicon Age / IC2 (буфер, вход 128 EU/t). Окно: категории (Компоненты / Машины /
  Блоки / Модули), поиск, сетка **5×5**, выход, полоса EU, прогресс; полупрозрачная подсказка рецепта и кнопка «Разложить»
  (берёт детали из инвентаря); NEI (R / U).
- Делает **все компоненты** (в центре 3×3 тоже работает) и **все машины** (решение 2026-10-06: «все машины делаются на этом верстаке»).
  Сборка тратит EU и время (багги — 200 тыс. EU, 30 с; тяжёлые машины — больше). Вход MV; для машин QV–SV нужен
  больший буфер/напряжение — Трансформаторный модуль и Модуль энергонакопителя ядра в слотах улучшений верстака.
- **Гараж** больше не собирает машины: только ремонт, модули, перекраска, заправка и зарядка внутри.
- Рецепт верстака: обычный верстак + стальной корпус ×4 + контроллер + медная катушка ×2 + MV-энергоячейка (SA + ваниль).
- Временный рецепт багги на обычном верстаке (этап 1) заменяется рецептом верстака.
- Макеты: `docs/mockups/veh_6_workbench_gui.png`, `veh_6b_workbench_gui_hint.png`, `veh_7_workbench_block.png`, `veh_8_workbench_recipes.png`;
  текстуры блока — `docs/mockups/textures/engWorkbench*.png`.

## 5. Реализация (Forge 1.7.10)
- **Проект**: `MineMod/SiliconAgeVehicles`, modid `SiliconAgeVehicles`, `dependencies = "required-after:SiliconAge@[0.1.8,)"`,
  ядро в `libs/` только для компиляции. Свой git-репозиторий, релизы, CHANGELOG, README (ru/en), самотесты.
- **Сущность** `EntityVehicleSC` (наследники по типам, параметры из enum `VehicleType`). NBT: EU, баки, нагрев,
  инвентарь, модули, владелец, доступ, схема, износ. ★ Предмет-машина хранит весь NBT: поставил — сущность,
  гаечный ключ мода (Shift+ПКМ) — снова предмет.
- **Места**: доп. сиденья — служебные сущности, привязанные к корпусу (в 1.7.10 один всадник на сущность).
- **Управление**: клиент водителя двигает машину (плавно), шлёт позицию; сервер проверяет скорость/телепорт и
  откатывает. Клавиши: WASD, пробел/Shift (вверх/вниз), F фары, R форсаж, H подвес/лебёдка, V вид, G HUD, C авто-пилот.
- **Лётная модель** (упрощённая): тяга, подъёмная сила (вертолёт — от шага винта; самолёт — от скорости²), сопротивление, вес.
- **Энергия**: расход каждый тик по формуле; зарядка — станция/плиты ядра (раз в секунду ищется под машиной);
  предмет-машина заряжается в зарядниках мода и IC2 (ISpecialElectricItem, как броня).
- **Газы**: баки в NBT по образцу `ArmorGasSC` ядра, дробные мБ копятся; заправка колонкой, ячейками, ведром.
- **Связь с ядром**: только открытые классы — `Tier`, `ArmorGasSC.Gas`/жидкости, `ModItems` (компоненты для рецептов),
  `ShieldEventHandler.privateFieldAgainst`, гаечный ключ, координатор (`ItemCoordinatorSC`). ★ Позже — маленький
  `com.sc.api` в ядре, если понадобится стабильность.
- **Рендер**: Java-модели (ModelRenderer), вращающиеся винты/колёса, цвет по схемам; HUD — по стилю мода.
- **Справочник**: свой раздел «Техника» (отдельная книга аддона или вкладка через API ядра позже).
- **Производительность**: машины без игрока не тикают физику (только остывание), никаких загрузок чанков.

## 9. Зарядная платформа (решение 2026-10-06: вариант 1 + все ★)
- **Плиты платформы** (новый блок) кладутся вплотную друг к другу и к **Зарядной станции техники** (контроллер) — объединяются
  в площадку любой формы; станция заряжает только машину, стоящую на своей площадке (несколько — по очереди).
- Размер площадки = какие машины помещаются: 3×3 (ховербайк, багги), 3×5 (вездеход, буровая), 5×5 (вертолёт, самолёт,
  конвертоплан), 7×7 (челнок, Сингулярный корабль); не помещается — сообщение.
- Скорость: уровень станции (MV…SV, улучшения ядра) + 10% за каждую плиту сверх минимума машины. Разметка: голубая — зарядка,
  зелёная — заряжено (звук, HUD «Зарядка: 64% · 1:20»).
- ★ Модули станции: **Газ** (Газовая колонка рядом подключается — заправка одновременно с зарядкой), **Ремонт** (чинит корпус
  стальными слитками из сундука рядом), **Доступ** (только свои машины / с ключ-картой). ★ Плиты «H» и края с огнями —
  авиаплощадка (заменяет отдельную вертолётную площадку). ★ Сигнал редстоуна при полной зарядке.
- Окно станции: карта площадки, карточка машины (EU / газ / корпус, время до полного), улучшения, модули, настройки,
  подключённые устройства, строка статуса. Макеты: docs/mockups/veh_9_platform_gui.png, veh_10_platform_world.png,
  veh_11_platform_tex.png; текстуры docs/mockups/textures/chargePlate_*.png, chargeStationFront2.png.
- Делается после этапа A (газы).
- **Быстрая зарядка (решение 2026-10-10):** площадка до 121 плиты (11×11 — корабль 7×7 получает +200% с 69 плит).
  Скорость = вход × настройка × 1,6^ускорители × (1 + бонус плит) × 2 (модуль «Быстрая зарядка», один; встроен в
  «Сингулярную зарядную станцию» SV — вход SV без трансформаторов) × 3 («Форсаж»: +1 нагрев за тик зарядки, 2400 = 2 мин →
  перегрев, пауза до 0 при −4/тик = 30 с; гелий из колонки через модуль газа 1 мБ/с — без нагрева). Несколько станций на
  одних плитах заряжают одну машину в один тик (общий выбор машины по времени мира), разметку показывает станция с
  наименьшими x, y, z. Накопитель ядра/IC2 выходом к станции: недостающее до скорости станции — прямо из него
  (extractForItemCharging), вход из сети с этой стороны закрыт. «Суперконденсатор станции» (XV): 50 млн EU, вход любой
  до 2048 EU/т, отдача машине 500 000 EU/т (на все станции рядом) сверх скорости. Настройки: stationBoost,
  stationStorageLink, stationsAddUp.
